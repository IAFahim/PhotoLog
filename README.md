# PhotoLog

Stamp a date/time (and optional address) onto photos, timestamp-camera style.

- **Hosted (this Space):** upload a photo folder, click thumbnails to select, Apply, download the zip.
- **Local (native experience, no upload):** clone the repo and run `uv run python main.py` — reads folders straight from disk, native folder dialog, output folder on your machine.
